## Ubuntu Server Home Lab

### Lab Environment
- Virtualization Platform: Oracle VirtualBox
- Operating System: Ubuntu Server 24.04.5 LTS
- CPU Architecture: ARM64 (aarch64)
- Allocated Virtual CPUs: 2
- Allocated Memory: 2 GB
- Virtual Disk: 25 GB
- Networking: NAT

### Linux Commands Practiced
- `pwd` — Display current directory
- `ls -a` — List files, including hidden files
- `whoami` — Identify current user
- `hostname` — Display server hostname
- `uptime` — Check server uptime
- `free -h` — Monitor memory usage
- `uname -m` — Identify CPU architecture
- `lscpu` — Display CPU information
- `df -h` — Check filesystem usage
- `lsblk` — Inspect disk and partition layout
